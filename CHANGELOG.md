# Changelog

## 1.1.1

- Essentials no longer go to sleep while you are in a workspace with a
  different container. Zen keeps separate Essentials per container and hides
  those of other containers from extensions, so they were mistaken for
  workspace tabs. Every pinned tab outside a folder now counts as a possible
  Essential.

## 1.1.0

- Renamed to Zen Tab Sleep, with an English and a German interface.
- In plain Firefox, tabs in tab groups now go to sleep on their own. Only Zen
  unloads a whole split view when one of its tabs is unloaded.

## 1.0.1

- Tabs in folders of the active workspace now go to sleep. Zen pins every tab
  in a folder, so they were mistaken for possible Essentials.

## 1.0.0

- First version.
